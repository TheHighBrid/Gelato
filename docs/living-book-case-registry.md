# Melato Living Book Case Registry

Updated: 2026-08-14

## Filing rule

A case is assigned only when source evidence supports the relationship between frames. The evidence hierarchy is:

1. Shopify image alt text with location and styling details
2. explicit shot-sequence filename
3. consistent filename family
4. existing archive source code
5. unresolved intake

Blank metadata is not converted into invented photoshoot attribution. Unknown frames remain visible and are filed as unresolved intake until they can be verified.

## Connection logic

The case order is narrative, not merely chronological:

Uniform -> construction -> performance -> raw contact -> recovered record -> afterimage -> specific location -> nocturne -> detail insert -> institutional portrait -> warm city sequence -> isolated portrait -> unresolved intake.

Every transition is rendered as a visible chain-of-custody handoff. This keeps each photoshoot distinct while giving the archive one continuous reading path.

## Commerce integrity

Product links are never inferred from filenames or visual similarity. The director carries a product CTA only when the source evidence card already exposes a structured Shopify product URL and title. Everything else remains editorial-only.
